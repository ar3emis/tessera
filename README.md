# Tessera

**AI-first procedural 3D for Windows.** Describe what you want; an AI builds a node graph live
in front of you: buildings, fairy-tale villages, eroded terrain, sculpted props, destruction, smoke, fire and water.
Tweak anything by hand, then send it straight into Unreal Engine with a live link.

- Website, documentation and support: **https://tessera.athiangames.com**
- Download the latest installer: **[Tessera-Setup-x64.exe](https://github.com/ar3emis/tessera/releases/latest/download/Tessera-Setup-x64.exe)**
- All versions: [Releases](https://github.com/ar3emis/tessera/releases)

## Highlights

- 160+ procedural nodes: modelling, attributes, curves, volumes/SDF, terrain with erosion, buildings and fairy architecture,
  sculpting, fracture + rigid bodies, cloth, particles, pyro, FLIP water, ocean.
- AI panel with your choice of AI: an offline local model (Ollama), Claude (your Claude Code login) or GPT (your ChatGPT login
  through the Codex app). An MCP server lets Claude Code drive Tessera from any project.
- Projects as tabs, graphs as tabs, graphs that combine other graphs; undo/redo; drag-to-scrub parameters;
  fly navigation (hold right mouse + WASD).
- Unreal Engine live link: send a node to the open editor and keep it updated as you edit.

## Install

Download `Tessera-Setup-x64.exe` and run it. The installer is self-contained (it bundles its own Python runtime and
geometry libraries). It is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC":
click **More info** then **Run anyway**. Requires Windows 10/11 x64.
